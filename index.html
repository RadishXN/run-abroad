请务必读一下

  • 这是初筛工具，不是法律意见。结果只说明「值得去查哪几条路」，不代表你一定能申请成功。
  • 移民政策变得很快。薪资门槛、名额、认可院校名单几乎每年都调整，每张卡片底部都有官网链接，最终以官网为准。
  • 警惕中介。本项目列出的绝大多数路径都可以自己 DIY 申请。任何声称「包过」「内部名额」的都要高度警惕。
  • 数据可能有错。欢迎在 GitHub 提 Issue 或 PR 纠正，见下方仓库链接。
