## 为什么做这个

想出国的人，通常最先遇到的不是「哪个国家好」，而是一个更基础的问题：

> **以我现在的条件，到底有哪些路是真的走得通的？**

网上不缺移民信息，缺的是**针对你个人情况的筛选**。你会看到几十篇「XX 国签证全解析」，每一篇都在讲政策条文，但没有一篇会告诉你：你 31 岁、双非本科、雅思 6.0、工作 6 年——**这些条件下，哪条路现在就能走，哪条路差一点，哪条路已经彻底关上了。**

于是你在几十个标签页之间反复比对，一周后仍然不知道下周该做什么。

这个项目就是来解决这一步的。它不是又一份签证清单，而是一个**决策工具**：把你的条件和 36 条路径的门槛逐项比对，输出一份排过序的、标注了具体缺口的结果。

### 三个核心设计

#### 1️⃣ 不做二元判断

现实中很少有人是「完全符合」或「完全不符合」。大部分人都卡在中间，所以结果分成四档：

| 分档 | 含义 |
|:---|:---|
| ✅ **符合条件** | 所列硬性门槛你都过了，可以直接去研究申请材料 |
| 🟡 **差一点** | 只差一两项，且都是能补上的（语言、经验、资金、offer） |
| 🟠 **需要长期准备** | 缺口较多，但方向上并没有被堵死 |
| ⚪ **暂时走不通** | 存在短期无法改变的硬门槛 |

#### 2️⃣ 区分硬门槛与软门槛

这是整个工具最关键的判断。同样是「不符合」，性质完全不同：

```
✕ 硬缺口 —— 短期内无法改变，只能绕开
   年龄超限 · 毕业超出窗口期 · 院校排名不够

△ 软缺口 —— 花时间或花钱可以补上
   语言成绩（英语 / 法语）· 工作经验 · 资金证明 · 雇主 offer · 学位就读地
```

一条路径如果只差软缺口，它就还在你的选项里，只是需要准备时间。如果卡在硬缺口上，再努力也没用，不如把精力放在别处 —— **知道哪条路不必再想，和知道哪条路能走，同样重要。**

#### 3️⃣ 告诉你先补哪一项最划算

这是比签证列表更有用的输出。引擎会统计**哪个缺口挡住了最多路径**：

```
先补哪一项最划算
  1. 提高语言成绩（考出雅思 6.5 或同等）    解锁 20 条路径
  2. 提升学历（读一个硕士）                 解锁 18 条路径
  3. 攒够资金证明                          解锁 9 条路径
```

你的时间和钱是有限的。与其平均用力，不如先打掉那个卡住最多可能性的瓶颈。

## 🚀 快速开始

没有构建步骤，没有 npm，没有任何第三方依赖。克隆下来直接打开：

```bash
git clone https://github.com/RadishXN/run-abroad.git
cd run-abroad

open index.html              # macOS 直接打开
python3 -m http.server 8000  # 或起个本地服务器
```

### 部署到 GitHub Pages

仓库已包含 GitHub Actions 工作流，推送即自动部署：

1. 仓库 **Settings → Pages → Source** 选择 `GitHub Actions`
2. 推送到 `main` 分支
3. 等待 Actions 跑完，站点上线

## 🧩 项目结构

```
run-abroad/
├── index.html          页面结构
├── css/
│   └── style.css       样式（自动适配深色模式）
└── js/
    ├── data.js         路径数据集  ← 绝大多数贡献都改这里
    ├── engine.js       匹配引擎：门槛判定、缺口分析、排序
    └── app.js          表单读写与结果渲染
```

三个 JS 文件按顺序用 `<script>` 引入，**刻意不做模块化和打包** —— 这样任何人都能直接改一行数据然后刷新看效果，降低贡献门槛。

## 🤝 参与贡献

**最有价值的贡献是纠错和补充路径。** 移民政策变动极快，任何一条数据都可能已经过时。

| 你想做的 | 怎么做 |
|:---|:---|
| 发现数据有误 | 提 Issue，**附上官网链接**（没有官方来源的修改无法合并） |
| 补充一条路径 | 照着 `js/data.js` 的格式加一个对象，见 [CONTRIBUTING.md](CONTRIBUTING.md) |
| 改进匹配逻辑 | `js/engine.js`，欢迎讨论打分权重 |
| 分享实操经验 | 路径的 `notes` 字段最需要的就是「别处查不到的坑」 |

写 `notes` 的原则：写**实操信息**，不要复述门槛。

- ✅ 「近年因申请量暴增设置了年度处理上限，等待期显著变长，市面上大量『包过』中介风险很高」
- ❌ 「这是一个适合年轻人的好签证」

### 提交前自检

打开 `index.html` 按 F12，`validatePathways()` 会在加载时自动校验重复 ID、缺失字段、未定义类型。

然后填几组不同条件，**确认新路径不会对所有人都显示「符合条件」** —— 这通常意味着漏写了某个门槛。

## 🔒 隐私

没有后端，没有数据库，没有分析脚本，没有 Cookie。

你填的所有信息只存在于当前页面的内存里，关掉标签页就没了。唯一的持久化是「复制结果链接」功能——它把你的选项编码进 URL，方便你保存或分享，**要不要生成完全由你决定**。

## ⚠️ 免责声明

**这是初筛工具，不是法律意见。**

- 结果只说明「值得去查哪几条路」，**不代表你一定能申请成功**。真实申请还涉及材料、背调、面试、行政审查等本工具无法覆盖的环节。
- **政策变动极快。** 薪资门槛、名额、认可院校名单几乎每年都调整。每张卡片底部都有官网链接，**一切以官网为准**。
- **警惕中介。** 本项目列出的绝大多数路径都可以自己 DIY 申请。任何声称「包过」「内部名额」「保证下签」的都要高度警惕。
- **数据可能有错。** 这是一个开源项目，欢迎提 Issue 或 PR 纠正。

本项目只讨论**合法的**移民与签证路径，不接受任何涉及伪造材料、虚假婚姻、非法滞留的内容。
