## 🧭 它和其他移民信息站的区别

网上不缺移民信息，缺的是**针对你个人情况的筛选**。你会看到几十篇「XX 国签证全解析」，每一篇都在讲政策条文，但没有一篇会告诉你：你 31 岁、双非本科、雅思 6.0、工作 6 年——**这些条件下，哪条路现在就能走，哪条路差一点，哪条路已经彻底关上了。**

这个项目不是又一份签证清单，而是一个**决策工具**：把你的条件和 171 条路径的门槛逐项比对，输出一份排过序的、标注了具体缺口的结果。

<table>
<tr>
<td width="50%" valign="top">

**常见的移民信息站**

- 按国家罗列签证政策
- 你需要自己对照条件
- 只告诉你「要求是什么」
- 符合 / 不符合的二元判断
- 看完仍然不知道先做什么

</td>
<td width="50%" valign="top">

**润学导航**

- 按你的条件筛选并排序
- 引擎自动逐项比对
- 明确告诉你「你还差什么」
- 四档分类，覆盖中间地带

### 三个核心设计

#### 1️⃣ 不做二元判断

现实中很少有人「完全符合」或「完全不符合」，大部分人都卡在中间，所以结果分成四档：

| 分档 | 含义 |
|:---|:---|
| ✅ **符合条件** | 所列门槛都过了，可以直接去研究申请材料 |
| 🟡 **差一点** | 只差一两项，而且都是能补上的 |
| 🟠 **需要长期准备** | 缺口较多，但方向上没有被堵死 |
| ⚪ **暂时走不通** | 存在短期内改不了的硬门槛 |

#### 2️⃣ 区分硬门槛与软门槛

同样是「不符合」，性质完全不同：

| | 包括 | 怎么办 |
|:---|:---|:---|
| ✕ **硬缺口** | 年龄超限 · 毕业超出窗口期 · 院校排名不够 | 短期内改不了，只能绕开 |
| △ **软缺口** | 语言 · 工作经验 · 资金 · 雇主 offer · 学位就读地 | 花时间或花钱可以补上 |

知道哪条路不必再想，和知道哪条路能走同样重要。

#### 3️⃣ 告诉你先补哪一项

引擎会统计**哪个缺口挡住了最多路径**，并参考补上它大约要多久，给出优先级。结果页上的样子大致是这样（数字仅为示例）：

| 先补哪一项最划算 | 解锁 | 预计准备 |
|:---|:---:|:---:|
| 1. 考出雅思 6.5 或同等成绩 | 20 条路径 | 约 2–12 个月 |
| 2. 读一个硕士 | 18 条路径 | 约 12–24 个月 |
| 3. 攒够资金证明 | 9 条路径 | 约 3–24 个月 |

> [!NOTE]
> 预估时间和费用档位（`js/engine.js` 里的 `GAP_EFFORT`）是粗略估计，只用于排序和展示，**不影响**分组判定，也不是成功率承诺。

## 🚀 快速开始

没有构建步骤，没有 npm，没有任何第三方依赖。克隆下来直接打开：

```bash
git clone https://github.com/RadishXN/run-abroad.git
cd run-abroad

open index.html              # macOS 直接打开
python3 -m http.server 8000  # 或起个本地服务器
```

<details>
<summary><b>部署到 GitHub Pages</b></summary>

仓库已包含 GitHub Actions 工作流，推送即自动部署：

1. 仓库 **Settings → Pages → Source** 选择 `GitHub Actions`
2. 推送到 `main` 分支
3. 等待 Actions 跑完，站点上线

</details>

JS 文件按顺序用 `<script>` 引入，**刻意不做模块化和打包** —— 这样任何人都能直接改一行数据然后刷新看效果，降低贡献门槛。

## 🤝 参与贡献

> [!TIP]
> **最有价值的贡献是纠错和补充路径。** 移民政策变动极快，任何一条数据都可能已经过时。

| 你想做的 | 怎么做 |
|:---|:---|
| 🐛 发现数据有误 | 提 Issue，**附上官网链接**（没有官方来源的修改无法合并） |
| ➕ 补充一条路径 | 照着 `js/data.js` 的格式加一个对象，见 [CONTRIBUTING.md](CONTRIBUTING.md) |
| ⚙️ 改进匹配逻辑 | `js/engine.js`，欢迎讨论打分权重 |
| 💬 分享实操经验 | 路径的 `notes` 字段最需要的就是「别处查不到的坑」 |

写 `notes` 的原则：写**实操信息**，不要复述门槛。

- ✅ 「近年因申请量暴增设置了年度处理上限，等待期显著变长，市面上大量『包过』中介风险很高」
- ❌ 「这是一个适合年轻人的好签证」

**提交前自检**：打开 `index.html` 按 F12，`validatePathways()` 会在加载时自动校验重复 ID、缺失字段、未定义类型和未归入地区的国家。然后填几组不同条件，**确认新路径不会对所有人都显示「符合条件」** —— 这通常意味着漏写了某个门槛。

## 🔒 隐私

没有后端，没有数据库，没有分析脚本，没有 Cookie。

你填的所有信息只存在于当前页面的内存里，关掉标签页就没了。唯一的持久化是「复制结果链接」功能——它把你的选项编码进 URL，方便你保存或分享，**要不要生成完全由你决定**。

## ⚠️ 免责声明

> [!WARNING]
> - 结果只说明「值得去查哪几条路」，**不代表你一定能申请成功**。真实申请还涉及材料、背调、面试、行政审查等本工具无法覆盖的环节。
> - **政策变动极快。** 薪资门槛、名额、认可院校名单几乎每年都调整，一切以官网为准。

> - **数据可能有错。** 这是一个开源项目，欢迎提 Issue 或 PR 纠正。

本项目只讨论**合法的**移民与签证路径，不接受任何涉及伪造材料、虚假婚姻、非法滞留的内容。
